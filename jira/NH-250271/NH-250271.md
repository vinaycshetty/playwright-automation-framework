## Description

This story covers all positive workflows - including importing files that have templates with the payment type Drawdown.

### Acceptance Criteria

- Users must have permission to both Import and Create Payment from Template for the **Drawdown** payment type. Users must have permission to restricted templates passed in the file, if applicable.
- User may or may not be entitled to the creation of Wire Domestic Payment type using the "Wires from Template"
- User may or may not be entitled to the creation of Wire International Payment type using the "Wires from Template"
- When a template sourced import map is selected, the import file must include the Template Code of the source template for each payment. Template must be in Approved status to be used as the source template.
- The resulting payments created through this workflow will have the Created from Template Entry Method.
- IMPORT PROCESS: When the "Wires from Template" map type is selected, the system will lookup the template code passed in the file, use that to create a payment, and update the rest of the data in the resulting payment from the values passed in the file.
  - The Template Code can belong to any of the 3 payment types - Wire International, Wire Domestic and **Drawdown**
  - The template name must be linked to the payment.
- There is no "Modification" audited as part of this process on the new payment. This should just look like a "create payment" in the audit.
- Until the payment is fully imported, it cannot be available for any actions from the payment list view.
- Payments can be imported with "Wires from Template" process in Test mode (resulting status = Test Entered).
